# GB-76: Refactor scripts/bootstrap.sh and Suite Setup Scripts to Wrap Outfeed Clone and Install

## Objective
Provide an idempotent, ergonomic entrypoint `scripts/bootstrap.sh` for new and existing developer environments in the `gaugeblock` meta-harness. The script bootstraps the seed `outfeed` CLI binary, and delegates repository cloning, dependency resolution, suite binary installation, and MCP server configuration directly to `outfeed clone` and `outfeed install`.

## Architecture & Invariants
1. **Submodule-Free Workspace (`suite.lock`):**
   - In accordance with the inherited architecture decision, member repositories are cloned as independent checkouts.
   - Pinned tags or commits defined in `suite.lock` can be automatically applied via `--locked`.
2. **Deterministic Seed Bootstrap:**
   - If `outfeed` is not already installed on `PATH`, `bootstrap.sh` verifies `cargo` and compiles `outfeed/crates/outfeed-cli` into `~/.cargo/bin`.
3. **Delegation to Dogfood CLI:**
   - Workflows delegate to `outfeed clone --all --install --sync-mcp` and `outfeed sync`.
   - Supports flag forwarding: `--protocol <ssh|https>`, `--locked`, `--no-install`, `--no-sync-mcp`, `--dry-run`, `--json`.

## Execution Plan
1. Create `scripts/bootstrap.sh` with robust error handling (`set -euo pipefail`), prerequisite checks, outfeed compilation fallback, and option parsing.
2. Ensure `scripts/bootstrap.sh` has executable permissions (`chmod +x`).
3. Refactor `scripts/install-suite.sh` to leverage `outfeed install --all` and `outfeed` built-in MCP sync capabilities.
4. Dogfood `scripts/bootstrap.sh --help` and dry-run execution.
5. Verify clean execution across workspace and finalize Storypole verification receipt.
