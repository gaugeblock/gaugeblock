# Task Plan: GB-131 — `gaugeblock-git`

> **Scope:** `common/crates/gaugeblock-git` **Parent epic:** `GB-128` **Status:** Planned

## 1. Why this crate exists

Six places currently spawn `git` with `format!`-built command lines and parse stdout by hand:

| Owner | Duplicated calls |
|:--|:--|
| `storypole-core::git` | current branch, head sha, merge base, `rev-list` between shas |
| `outfeed-core::git` | dirty tree, commit + annotated tag, push, tag verify |
| `benchwork-core` | dirty tree, head sha, scoped commit for Panel 1 |
| `miter` (`deps --since`) | commit ranges |
| `rabbet` (backfill) | commit ranges, head sha |
| `scripts/*.sh` | branch, tags |

`GB-126` already collapsed the worst copy inside `outfeed`. This ticket generalizes the winner and
relocates it, it does not write a seventh wrapper.

## 2. Boundary (frozen — see `common/ARCHITECTURE.md` §4)

**Owns:** repository detection (`common_dir`, worktree vs main checkout), `worktree add/remove/prune/list`,
`rev-list`/`merge_base`/tag ranges, scoped `status`/`add`/`commit`/annotated `tag`, `push`.

**Does not own:** which repository to act on, `.gaugeblock/` resolution, workspace config, and any suite
type (`TaskNode`, `ReleasePlan`). A caller hands it a `Path` and typed arguments; it returns values or a
`thiserror` error carrying stderr. It never depends on `gaugeblock-workspace` — the edge is one-way
(`GB-189` -> `GB-131`).

## 3. Steps

| # | Step | Gate |
|:--|:--|:--|
| 1 | `repo` module: `common_dir`, `is_worktree`, `head_sha`, `current_branch`, `is_dirty` | `cargo nextest -p gaugeblock-git` with a temp repo + linked worktree fixture |
| 2 | `worktree` module: `add`, `remove`, `prune`, `list` returning typed `WorktreeInfo` | fixture asserts two worktrees share one `common_dir` |
| 3 | `history` module: `commits_between`, `merge_base`, `describe_range` (replaces `rev-list` string parsing) | fixture with a 3-commit range |
| 4 | `index` module: scoped `stage_paths` + `commit` returning a typed `CommitSummary` | fixture asserts only the named paths are staged (`GB-150` staging rule) |
| 5 | `remote` module: annotated `tag` + single-round-trip `push_branch_and_tag` | dry-run against a local bare remote |
| 6 | Delete `storypole-core::git`, `outfeed-core::git` and the benchwork copy; re-point callers | `cargo nextest --workspace` in each affected repo |
| 7 | `miter contracts` + `chalkline docs check` green | Tier 3 |

## 4. Consumers this unblocks

* `GB-169` — canonical `.gaugeblock` across worktrees needs step 2 and step 1 in that order.
* `GB-170` — benchwork agent pool needs `worktree add/remove/prune/list`.
* `GB-180` — Panel 1 atomic doc commits need step 4 (scoped staging, no `git add .`).
* `outfeed release` — needs step 5 for the single push.

## 5. Explicitly out of scope

* `codegen-units` tuning — moved to `GB-190` because it is a profile decision, not a crate boundary.
* Path/topology/config policy — `GB-189`.
