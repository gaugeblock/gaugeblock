# GB-86: Suite-Wide 9-Document Architecture Rollout & Standardized READMEs

## Vision & Architecture Overview
This epic aligns documentation across the entire `gaugeblock` ecosystem with the canonical 9-document architecture defined in GB-18 and enforced by `chalkline docs check`.

1. **Member README Standardization:**
   Every member repository README will follow a strict 9-section architecture:
   - Header with badges (Version, License: Apache-2.0, Suite: gaugeblock, CI/Docs)
   - Woodworking Metaphor & Elevator Pitch
   - Architecture & Mental Model (ASCII flowcharts / diagrams)
   - Core Capabilities & Features
   - Crate Structure & Responsibilities
   - CLI Quickstart & Command Cheatsheet
   - Model Context Protocol (MCP) Tool Reference
   - Verification & Development Invariants (file limits, Tier 1–3 checks)
   - License & Ecosystem Links

2. **AST-Grounded 9-Doc Scaffolding:**
   Dogfood `chalkline docs scaffold` to establish the required 6-document tier in every member repo:
   - `README.md`
   - `CONTRIBUTING.md`
   - `ARCHITECTURE.md`
   - `SPEC.md`
   - `CHANGELOG.md`
   - `AGENTS.md`
   (while `PRODUCT.md`, `DESIGN.md`, and `ROADMAP.md` remain housed at the meta-harness root).

3. **Drift Resolution & Verification:**
   - Resolve `CHANGELOG.md` unreleased markers (`## [Unreleased]`).
   - Audit every repository with `chalkline docs check` as a mandatory Tier 3 completion gate (0 missing, 0 drifted).
