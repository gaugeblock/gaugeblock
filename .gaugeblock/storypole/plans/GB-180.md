# Task Plan: GB-180 — Native Frontend Toolchain + Rust Dev-Profile Tuning

> **Key:** `GB-180` **Scope:** `benchwork/web`, `benchwork/Cargo.toml` **Status:** Planned

## 1. Baseline (measured under GB-71, Law 12)

| Phase | npm | Bun | Toolchain |
|:--|--:|--:|:--|
| install, cold cache | 27.89 s | 13.21 s | npm 12.0.2 / Bun 1.4.4 |
| install, warm cache | 15.22 s | 1.13 s | same |
| build (`tsc -b` + `vite build`) | 27.58 s | **29.32 s** | TypeScript 5.7, Vite 6 |

Environment: macOS Apple silicon, Node 24.21.0. Timed phases run **sequentially**; parallel runs were
shown to produce noise when `GB-71` was first measured.

## 2. Method (every slice, every time)

1. `rm -rf node_modules` for a cold phase, keep it for the warm phase.
2. Time with `/usr/bin/time -p sh -c '<commands>'` so one number covers the whole phase.
3. Record: platform, tool versions, `bun.lock` state, cold/warm, and the exact commands.
4. Write it in three places - commit message, this ticket, and `benchwork/CONTRIBUTING.md`.

## 3. Slices, each independently measured and committed

| # | Change | Risk |
|:--|:--|:--|
| 3.1 | `incremental`, `skipLibCheck`, `tsBuildInfoFile` in `tsconfig` | low |
| 3.2 | Native typecheck: `typescript@7` if published, else `@typescript/native-preview` (`tsgo`) | medium - peer ranges may pin 5/6 |
| 3.3 | `vite@^8.1` via `rolldown-vite` first if the jump spans Vite 7 | medium |
| 3.4 | Config key migration: `rollupOptions`→`rolldownOptions`, `manualChunks`→`codeSplitting.groups`, `esbuildOptions`→`rolldownOptions`, `esbuild`→`oxc` | medium |
| 3.5 | `build.reportCompressedSize: false`, `server.forwardConsole: true` | low |
| 3.6 | Rust `[profile.dev]`/`[profile.test]`: `incremental = false`, `debug = 1`, `split-debuginfo = "unpacked"` | medium |

**Config names in 3.4 are expectations, not verified facts.** Each rename is checked against the
installed Vite 8 documentation before the commit that claims it.

## 4. Acceptance

* One table per slice: cold and warm, before and after, same machine.
* `bun run build` still produces a bundle that loads (`bun run preview` + a Playwright smoke run).
* `outfeed gate -d benchwork` green after every slice - this is a web change, but the gate also covers
  docs and the Rust crates that consume `web/dist`.
* Rust slice reports `outfeed gate` wall time and `target/` size before and after, and says plainly if
  it regresses.
